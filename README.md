# Arduino IoT Lab Experiments

A collection of **Arduino Uno programs for IoT and Embedded Systems laboratory experiments**.

## Experiments

- 4×4 Keypad Interfacing
- Ultrasonic Water Level Monitoring
- UART Communication
- DHT11 Temperature & Humidity Monitoring with LCD
- Smoke Detection using MQ Sensor and LCD
- Smoke Detection using MQ Sensor and Buzzer
- pH Sensor Interfacing with LCD
- Soil Moisture Sensor with LED
- Smart Street Light using LDR
- Bidirectional DC Motor Control
- DC Motor Control using Relay
- Ultrasonic Distance Detection with Buzzer
- Relay-Controlled Bulb
- Running LED / LED Chaser

## Hardware

- Arduino Uno
- Sensors and modules used in the experiments
- 16×2 LCD
- LEDs and Buzzers
- DC Motor
- Relay Module
- Motor Driver
- Breadboard
- Resistors and Jumper Wires

## Software

- Arduino IDE
- Arduino Uno
- Required Arduino libraries where applicable

## Topics Covered

- Digital and Analog I/O
- Sensor Interfacing
- Actuator Control
- ADC and Threshold-Based Control
- LCD Interfacing
- UART Communication
- Ultrasonic Distance Measurement
- Motor and Relay Control
- Basic IoT Automation

> **Note:** Check the wiring and component specifications before connecting hardware, especially motors, relays, and external power supplies.
